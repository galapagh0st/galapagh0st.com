# Command Injection

## Exploitation - Detection

Detection is the same methodology and actually exploiting

| Operator   | Injection | command executed                       |
| ---------- | --------- | -------------------------------------- |
| Semicolon  | ;         | Both                                   |
| New Line   | \n        | Both                                   |
| Background | &         | Both -> Second output shown firsdt     |
| Pipe       | \|        | Both -> Only second output is shown    |
| AND        | &&        | Both but only if first command success |
| OR         | \|\|      | Second but only if first fails         |
| Sub-Shell  | ``        | Both -> Linux Only                     |
| Sub-Shell  | $()       | Both -> Linux Only                     |
